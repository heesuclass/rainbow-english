Team Battle Board

TV 팀 대항전

TV에 띄우는 번호판 게임. 영어 미션 + 깜짝 이벤트(뺏기·바꾸기·폭탄)로 끝까지 역전 가능! 태블릿 없이도 OK.

📺 선생님 PC → TV⏱️ 10~20분🗣️ 말하기·듣기

👩‍🏫 선생님 코너

⭐ 우리반 단어장 만들기 (교과서 단원 단어 넣기)
한 줄에 하나씩, 영어 | 뜻 | 이모지 순서로 써요. 이모지는 비워도 돼요. 문장은 영어 문장 | 뜻.
저장하면 모든 게임의 주제 목록 맨 앞에 ⭐ 우리반 단어장이 생겨요. (단어 최소 6개, 문장 4개 이상 추천)
💡 단어장은 기기마다 따로 저장돼요. 태블릿 5대에 똑같이 넣으려면 공유 링크를 복사해서 QR코드로 만들거나 메시지로 보내 열면 자동으로 들어가요. (게임을 인터넷 주소로 열었을 때 사용)
📲 태블릿에 앱으로 설치하기
① 처음 한 번만 인터넷 연결 — 핫스팟을 켜고 게임 주소를 열어요. 위쪽에 ✅ 오프라인 준비 완료가 보이면 게임 8개와 글꼴이 태블릿에 저장된 거예요.
② 홈 화면에 추가
  • 갤럭시탭(크롬/삼성 인터넷): 위의 📲 앱 설치 버튼, 또는 메뉴(⋮) → 홈 화면에 추가 / 앱 설치
  • 아이패드(사파리): 공유 버튼 ⬆️ → 홈 화면에 추가
③ 영어실에서는 홈 화면의 🌈 아이콘을 누르면 와이파이 없이 바로 실행돼요. 주소창 없이 전체 화면으로 떠요.
• 게임을 고친 새 버전을 올리면, 다음에 인터넷이 될 때 자동으로 업데이트돼요.
📶 태블릿 4~5대 운영 팁
• 모든 게임은 한 번 열면 인터넷 없이 돌아가요. 핫스팟은 처음 페이지를 열 때만 필요해요.
• 더 안전하게: 게임 파일(.html)을 태블릿에 저장해 두면 핫스팟 없이도 열 수 있어요. (같은 폴더에 두어야 🏠 버튼이 작동)
• 듣기 문제는 태블릿의 영어 읽어주기(TTS)를 써요. 소리가 안 나면 설정 → 텍스트 음성 변환에서 영어 음성을 받아 주세요.
• 모둠 기록은 태블릿 결과 화면을 들고 와서 보여 주거나, TV 대항전 점수판에 선생님이 반영하면 돼요.
• 태블릿이 4대뿐이면: 4모둠은 태블릿 게임, 나머지 1모둠은 선생님과 TV 대항전 → 순환!
